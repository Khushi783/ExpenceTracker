Algorithm Demonstration

Explanations, pseudocode and complexity for every algorithm in this project — plus a live, interactive demo below.

Linear Search

Scans every element sequentially until a match is found.

Pseudocode

for i = 0 to n-1:
    if arr[i] == target: return i
return -1
Time: O(n)Space: O(1)

Advantages

Simple; works on unsorted data.

Disadvantages

Slow on large datasets.

Binary Search

Repeatedly halves a sorted array's search interval.

Pseudocode

low=0, high=n-1
while low <= high:
    mid = (low+high)/2
    if arr[mid]==target: return mid
    elif arr[mid]<target: low=mid+1
    else: high=mid-1
return -1
Time: O(log n)Space: O(1)

Advantages

Very fast on large sorted datasets.

Disadvantages

Requires sorted data first.

Bubble Sort

Pseudocode

for i = 0 to n-2:
    for j = 0 to n-i-2:
        if arr[j] > arr[j+1]: swap(arr[j], arr[j+1])
Time: O(n²)Space: O(1)

Advantages

Easiest to understand.

Disadvantages

Very slow on large data.

Selection Sort

Pseudocode

for i = 0 to n-2:
    minIdx = i
    for j = i+1 to n-1:
        if arr[j] < arr[minIdx]: minIdx = j
    swap(arr[i], arr[minIdx])
Time: O(n²)Space: O(1)

Advantages

Fewer swaps than Bubble Sort.

Disadvantages

Still O(n²) in all cases.

Insertion Sort

Pseudocode

for i = 1 to n-1:
    key = arr[i]; j = i-1
    while j>=0 and arr[j]>key:
        arr[j+1] = arr[j]; j--
    arr[j+1] = key
Time: O(n²)Space: O(1)

Advantages

Efficient on nearly-sorted data.

Disadvantages

Inefficient on large random data.

Merge Sort

Pseudocode

mergeSort(arr, l, r):
    if l < r:
        mid = (l+r)/2
        mergeSort(arr, l, mid)
        mergeSort(arr, mid+1, r)
        merge(arr, l, mid, r)
Time: O(n log n)Space: O(n)

Advantages

Consistent performance, stable sort.

Disadvantages

Needs extra memory for merging.

Quick Sort

Pseudocode

quickSort(arr, low, high):
    if low < high:
        p = partition(arr, low, high)
        quickSort(arr, low, p-1)
        quickSort(arr, p+1, high)
Time: O(n log n) avgSpace: O(log n)

Advantages

Very fast in practice, in-place.

Disadvantages

Worst case O(n²).
